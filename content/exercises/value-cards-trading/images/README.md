# Card images

Drop an image file here (PNG, JPG, or SVG) and put its filename in the
`image` column of `cards.csv`, on that card's row. Leave the `image` cell
blank for a card whose face should be generated from its text fields
instead - both are fine in the same deck.

`equal-standing.png` in this folder is a placeholder showing the
convention, not real card art. Replace it (and update the filename in
`cards.csv` if you rename it) with the real image when it's ready.
